# Alzikrayat

## Project Name

Alzikrayat — MVC Photo Sharing Web Application

## A Simple Description

Alzikrayat is a web-based photo sharing application developed using PHP and MySQL.

Users can register and log in, upload and manage their own photos, view photos in a gallery, add comments, and apply image filters such as grayscale, sepia, and invert.

The project follows the MVC and 3-Tier architecture and uses a custom manual regex router.

## Technologies

- PHP
- MySQL
- PDO
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- PHP GD
- MVC Architecture
- 3-Tier Architecture
- Manual Regex Routing

## How to Run

1. Install and start Apache and MySQL using XAMPP.
2. Copy the `alzikrayat` project folder into:
   `C:/xampp/htdocs/`
3. Open phpMyAdmin.
4. Import the database file:
   `database/alzikrayat.sql`
5. Check the database credentials in:
   `config/database.php`
6. Make sure the PHP GD extension is enabled.
7. Open the application in your browser:

   `http://localhost/alzikrayat/public/`
